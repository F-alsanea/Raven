# Raven upstream tracking

Raven is based on DeepSeek Harness.

- Upstream repository: `https://github.com/deepseek-ai/deepseek-harness.git`
- Upstream branch: `master`
- Mirrored snapshot branch: `upstream/deepseek-harness`
- Raven development branch: `raven/integration`
- Exact imported upstream commit: see `.raven-upstream-sha`

Upstream GitHub workflow files are intentionally excluded from the mirrored snapshot because the repository automation token cannot publish third-party workflow files. Raven owns its own CI workflows.

The original DeepSeek Harness license is preserved as `LICENSE.deepseek-harness`.
Raven-specific code is covered by the repository `LICENSE`, unless otherwise noted.
